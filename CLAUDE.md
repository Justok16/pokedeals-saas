## Conventions de travail

- **Mandat d'autonomie élargi (30/08/2026)** : Justok a explicitement donné l'autorisation permanente d'agir sans demander confirmation au préalable — diagnostiquer, corriger, tester, committer, pousser, ouvrir une PR **et la merger soi-même** une fois la CI (ou le build local `npm run build`/`npm run lint` en l'absence de CI) verte, sur ce repo comme sur les autres du compte (`pokedeals`, `pokeprecoms`, etc.), quelle que soit la conversation. Le prévenir après coup (résumé bref), jamais avant, sauf dans les cas ci-dessous. Limites qui restent systématiques, pas par méfiance mais parce que ce sont des actions à sens unique : jamais de force-push, `git reset --hard`, ou suppression de données sans signal explicite ; jamais d'action qui dépense de l'argent réel ou touche irréversiblement un service tiers (Vercel, Supabase...) ; **toute migration SQL dans `supabase/migrations/` reste à appliquer manuellement par Justok** (cf. README.md — pas d'accès direct à la base depuis ce repo) ; toujours s'arrêter et demander l'avis de Justok face à un changement d'architecture, un comportement métier ambigu, ou toute situation où la confiance dans le correctif est <90%.
